# Blender Cute Shooter

## 概要

> Blenderを使った3Dモデリングに興味を持ち、せっかくなら「自分で作った可愛いキャラクターをブラウザ上で自由に動かせるゲームを作りたい！」と思ったのがきっかけです。Webでの3D表現を可能にするThree.jsというライブラリを知り、開発のなかでAIのサポートも借りながら、手軽に遊べる3Dシューティングゲームを一から作ってみることにしました。

## アプリのURL

> こちらから実際に公開しているアプリをご覧いただけます：[https://s1324121.github.io/blender-cute-shooter/](https://s1324121.github.io/blender-cute-shooter/)

## 主な機能

> * 3D空間を自由に動き回るプレイヤーの操作機能
> * 自作の可愛いターゲット（エネミー）を狙って撃つシューティング機能
> * 弾が当たったときのエフェクトやスコアのカウント機能
> * ゲームの開始や終了がわかりやすいシンプルな画面遷移
> 
> 

## 使った技術

> * HTML5 / CSS3
> * JavaScript（Three.js）
> * Blender（キャラクターや背景などの3Dモデル作成）
> * 生成AI（コードのデバッグや、Blenderの操作方法のアドバイスに活用）
> 
> 

## こだわった点・工夫したところ

> 一番苦労したのは、Blenderで作った3DモデルをThree.jsを使ってブラウザ上に綺麗に読み込み、違和感なくスムーズに動かすところでした。最初はモデルのデータが重すぎて動きがカクカクしてしまいましたが、ポリゴン数を減らす方法をAIに相談したり、テクスチャのサイズを工夫したりして、ブラウザでも軽快に動くように調整しました。
> また、Three.jsでのカメラの動かし方や当たり判定の実装でエラーが出たときも、AIをペアプログラミングの相手のように活用してエラー原因を特定し、効率よく解決することができました。遊んでいて「楽しい」と思えるエフェクトの演出など、細かい画面づくりまでこだわってコードを書いています。

## 使い方

> 1. ブラウザでゲームのURLを開きます。
> 2. 画面上のスタートボタンを押すとゲームが始まります。
> 3. キーボード（W/A/S/Dキーなど）で移動し、マウスのクリックで狙いを定めて弾を発射します。
> 4. 体力がすべてなくなるまでにたくさんのターゲットを倒して高得点を目指してください。
