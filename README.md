# Blender Cute Shooter

BlenderとThree.jsを用いて作成した、Webブラウザで動く3Dシューティングゲームです。

### 🛠️ 開発の工夫（AIのフル活用）
最新の効率的な開発手法を実践するため、AIをペアプログラミングの相手としてフル活用しました。
Three.jsの複雑な3Dレンダリングのベース構築やエラーの解消はAIに委ね、自分自身はゲームのスピード感や色味などのデザイン調整、およびGitHub Pagesでの公開作業といったディレクションに注力しました。

AIへの適切な指示（プロンプト）によって、未経験からでも短期間で作品を形にする実行力を学びました。
